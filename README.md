## Descripción
CookBook es una aplicación móvil desarrollada con React Native CLI que permite explorar un catálogo de recetas de cocina, ver el detalle completo de cada una, registrar nuevas recetas mediante un formulario y consultar tips culinarios que rotan automáticamente cada 5 segundos.

## Tecnologías utilizadas
- React Native CLI
- React Navigation (Stack Navigation + Bottom Tab Navigation)
- React Hooks (useState, useEffect)
- StyleSheet (estilos separados por pantalla)
- JavaScript ES6+

## Instrucciones de instalación y ejecución

### Requisitos previos
- Node.js >= 18
- JDK 17
- Android Studio con un emulador configurado o dispositivo físico con depuración USB activada
- React Native CLI

### Pasos

1. Clonar el repositorio
   git clone https://github.com/juancamolina6/CookBook.git
   cd CookBook

2. Instalar dependencias
   npm install

3. Ejecutar en Android
   npx react-native run-android
